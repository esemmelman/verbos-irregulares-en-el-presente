# Spanish vocabulary: present tense

Open `index.html` in a browser. No build or installation is required.

Words follow the five supplied images in reading order. Repeated words are removed without regard to capitalization. Gray input boxes, Answer sections, grading labels, and teacher feedback are excluded. A word appearing outside a gray box is retained even if it also appears inside a box elsewhere.

Click a word to switch between Spanish and English. Revealing English speaks the English translation after a 0.25-second pause at 70% of normal speed. Switching back or playing another word cancels pending audio. Slow and Normal (in that order) always speak the original Spanish using the browser's speech synthesis and available Spanish voices. Audio availability depends on the browser and installed voices.

The page displays version v1.1.1 beside the title.

The default word size is Extra large (80px), with 48px and 64px options. The page includes high contrast, visible keyboard focus, native buttons, and responsive audio controls to the right of each word.
